# Khel Naksha — deadline prototype

Open `index.html` directly. No Node.js or npm is required.

The India map is the home navigation. The supplied Ashta Chamma and Vaikuntapali board images are used only inside their respective game pages. The Aadu Huli source supplied by the user is retained in `assets/aadu-huli-source.html`.

This is a static prototype. Regional rules and names can vary by community and should be verified with sources/contributors before publication.
